# 0.4.2：角色卡明文解析与世界书预算

## 世界书兼容修正

旧导入器在原始世界书没有 `token_budget` 时额外写入 2048 本书上限，使会话额度增加到 8192 后仍被拦截。新导入默认跟随会话预算；旧数据在原文未设置预算、现有本书额度仍为默认 2048 时按跟随会话解释，无须重新导入。原文明确设置的预算（包括 2048 / 0）和已调整的非默认额度保持生效。旧格式不能区分“在原文未指定预算的书上手动设置回 2048”和“从未修改过的默认 2048”，这种情况下需在编辑页关闭跟随并重新保存独立限额。

- 世界书编辑页可切换“跟随会话预算”或独立限额；多本书仍共享会话总额度。
- 会话编辑页显示每本绑定书的预算模式；当前会话的修改不会被继承到另一个新会话。
- 上下文预览显示已用 / 总额度，以及每本书的额度；明确区分已触发但因会话总额度或本书限额被跳过，并显示条目需求量。
- 0 仍表示不分配额度，未变成无限制；token 仍是估算。

## 解析器

设置 → 角色卡解析器，可选择原始 PNG / JSON 或读取已导入角色保存的原始资料。展示角色设定、开场白、世界书设置、所有条目（包括停用条目）和扩展文字；支持全文搜索、选择文字、导出 TXT 明文或格式化 JSON。导出不改变现有角色、世界书或会话，不执行宏、JavaScript、HTML 或正则；沿用导入器对密钥字段的移除规则。

解析在后台线程运行；大字段按 2000 字符分段在懒列表中展示，原始结果保留在 ViewModel 而非 SavedState/Bundle。导出保存完整文本。屏幕旋转保留结果及待导出内容。

本次收到的 `V2.0.png` 实际字节头是 JPEG（FF D8 FF E0），1024×1536，254345 字节，仅有图像数据 / JFIF / ICC 信息，没有 PNG `chara` / `ccv3` 元数据，因此不能从本附件还原世界书。不能将合成测试内容当作该私人角色卡的解析结果。用户可在解析器中读取其设备内已导入的完整角色，或提供原始文件。

## 验证范围

回归用合成角色卡覆盖缺省 / 显式 / 旧格式 / 修改后的本书预算、0 额度、已触发条目诊断、PNG 元数据读取、停用条目和扩展保留、伪装 PNG 的 JPEG 拒绝、存量角色、搜索、TXT / JSON 导出及活动重建。上一版本的大预设持久化和数据库恢复测试继续运行。真实附件仅验证文件格式及元数据缺失，不声称复现它全部世界书内容。
