# 阅读界面与长剧情记忆（未发布）

本轮从已验证的 `08ca058` 开始，按基础验收、UI、长剧情记忆、兼容诊断的顺序推进。用户允许调整布局，要求保持简洁；继续保留源码，不交付新的 APK。

## 界面

- 中性色背景、少量柔和紫色、统一间距与圆角，深浅主题采用同一套层级。
- 会话首条突出“继续上次”，展示实际最近正文的安全文本预览和直接继续按钮。可搜索标题及最近剧情；删除收进会话操作菜单。
- 角色保留头像、场景简介、直接开始会话与编辑；导出收进次要菜单。自定义头像继续仅用于角色库和会话列表，聊天正文不显示头像。
- 资料库统一标题与类型切换；编辑和启停直接可达，导出、删除收进菜单。预设和世界书的专用文件导入入口保留。
- 聊天标题可点开模型选择；剧情记忆有独立入口。消息操作目标扩大为48dp；字号14～22、行距跟随字号，阅读模式可移除角色回复气泡。Token开关、停止、续写与回到最新仍保留。
- 大屏限制正文宽度，减少横向拉长；未加入平板列表详情双栏。背景图、群聊、语音和图像生成继续留待后续。

## 记忆

- 固定记忆由用户维护；生成摘要独立存放于会话配置，不覆盖角色卡。摘要可查看、修订、清除，展示来源消息范围。
- 手动生成使用当前会话的API与模型，将旧剧情发送给该服务商并产生额外用量；生成后须保存才能采用。
- 自动整理默认关闭；明确启用后，正常回复完整结束时检查是否新增20条可整理的旧消息，自动保存并提示。最近12条完整消息始终保留；一次输入至多60000字符且不拆消息。
- “用摘要替代已整理的旧消息”独立控制，默认关闭。开启时仅发送已验证摘要、未整理的历史及未完整生成的片段；本地聊天原文保留。
- 每份摘要保存覆盖范围、条数与来源内容指纹。摘要范围内的消息被改动、删去或回滚时不再发送该摘要；分支仅继承所有来源仍完整一致的摘要。
- 备份恢复和分支会生成新消息ID，来源指纹不依赖ID，仍可验证。新会话清除生成摘要，不继承上个故事的剧情。
- 失败、取消、空回复、输出截断及来源变化均不替换原有摘要。不因API调用失败静默换服务商；未使用真实密钥进行付费测试。
- 摘要不是保证模型记忆准确的机制；用户仍可修订固定记忆和摘要。摘要过长仍受上下文预算约束。

## 兼容诊断

- 上下文预览增加世界书未插入的原因：整本/条目停用、空内容、关键词与扫描深度、辅助条件、概率及预算。每次最多展开256条，额外数量明确提示。
- 角色卡解析器增加兼容性报告，区分常用字段转换、关联资料、原生可读显示和未执行扩展。原始CSS布局不会完整复现；酒馆助手、MVU、STscript与任意JavaScript不执行。
- 本轮没有添加全量酒馆脚本兼容，也没有声明四家服务商的真实网络调用全部验收。
