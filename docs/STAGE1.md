# 第一阶段：安卓基础客户端

此阶段将聊天持久化、草稿恢复和记录备份作为基础能力。世界书、酒馆资料导入、提示词预设和正则仍属于下一阶段，当前界面会明确提示。

## 当前实现

- 中文原生界面：会话、角色、资料库、设置；浅色/深色模式。
- 创建和编辑角色，配置描述、性格、场景、开场白、对话示例。
- 会话创建时保存角色快照。修改角色不会自动改变旧会话。
- 多个 API 连接；DeepSeek、OpenAI、Claude、Grok 模板及自定义地址。
- Chat Completions、Responses、Anthropic Messages 三种协议编码与流式解析。
- 模型列表获取、手动模型 ID、简短生成测试、HTTPS、中文错误提示。
- 本地 Room 数据库存储会话、消息、草稿；启动恢复上次打开的会话。
- API 调用使用当前会话完整历史，关闭再打开不依赖服务商的会话 ID。
- 流式回复约每 180 ms 持久化一次；正常结束或停止时保存最终片段。
- 进程突然终止时，保留最后一次已提交的片段，未完成消息标记为中断；不自动重复付费请求。
- 停止生成、剧情续写、文字选择复制、聊天上下文检查。
- 每个会话可导出 JSON 可恢复记录、TXT 阅读文本；可导出全部资料的 JSON 备份。
- 导入前预览数量；校验文件格式、引用、排序与角色快照。事务写入，合并新增副本，不覆盖现有记录。
- API 密钥使用 Keystore 加密保存；备份仅含连接元数据，不含密钥。
- 服务商、地址或协议改变时，禁止静默复用原密钥；HTTP 重定向不自动携带凭证跟随。

## 使用路径

1. 打开“设置 → 添加连接”，选择服务商，输入自己的密钥与模型 ID。
2. 可点击“获取模型列表”。如果服务商不支持，直接手动填写模型 ID。
3. “测试生成连接”会发送一条简短消息并产生少量 API 用量；通过后保存。
4. 打开“角色”，选择林舟或新建角色，点击“开始新会话”。
5. 会话菜单可以选择连接、导出记录、查看上下文。新会话暂默认使用第一条已保存连接。
6. 退出 App 后再打开，会恢复上次打开的会话。未发送草稿也保留。
7. 单个会话使用菜单导出；所有数据从“资料库”或“设置”导出完整备份。
8. 在另一台设备安装后导入 JSON。为导入的连接重新填写密钥即可继续对话。

## 文件格式和恢复行为

完整备份的 format 为 roleplay.backup，单会话为 roleplay.chat，version 为 1。
两者包含角色、连接元数据、会话和消息。角色快照、草稿、消息顺序和消息状态都保留。

TXT 是供阅读的文本，不能完整恢复角色与会话结构。当前仅能导入本 App 的 JSON 记录，尚不支持 SillyTavern JSONL 聊天、角色卡 PNG、世界书等社区文件。

导入为合并新增：所有内部 ID 重新分配，避免覆盖原有资料；重复导入会产生副本。生成中的备份可保留已提交片段，恢复后该消息为“中断”。文件大小当前限制为 16 MB。

聊天不放在系统缓存目录。正常清除缓存不会清除数据库；卸载、清除应用数据或设备损坏可能导致本地记录丢失，应使用导出备份。当前没有自动云同步，手机和平板通过文件导入导出迁移。

## 构建

JDK 17、Android SDK 35、Gradle 8.9。依赖版本固定在 Gradle 配置中。

```bash
gradle testDebugUnitTest assembleDebug lintDebug
gradle connectedDebugAndroidTest
```

GitHub Actions 自动构建测试 APK，并运行数据库恢复、备份往返和 UI 生命周期检查。APK 位于 Actions 的 roleplay-0.1.0-test-apk 构建产物。

构建和设备测试结果将在完成后记录在本文，不把未完成的检查标成通过。
