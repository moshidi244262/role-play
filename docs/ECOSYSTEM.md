# 0.4.0：酒馆文本生态兼容与可搜索帮助

在 0.3.2 上加入专用预设 / 世界书文件导入和设置里的帮助页。帮助包含定义、作用、操作路径、适用情况、不需要的情况、排查和兼容限制，支持标题/正文/别名搜索和分类。世界树别名关联世界书。

## 本轮变化

- 资料库世界书、预设页均有对应文件入口；编辑页也可重新选择文件。导入预览新增副本；错误类型不会写入。文件仍限制 16 MiB，在后台读取和解析。
- 酒馆预设保留最多 1000 个块，包括空分组块、暂未加入排列的块和常用占位块。100001 全局排列优先；未列入当前排列的块停用。保留原顺序，聊天历史后的相对提示不再移到历史前，名称不会作为额外提示发送。
- 占位块包括人物描述、性格、场景、玩家身份、世界书前后、示例对话、聊天历史；缺失历史块会补入本轮消息并提示。人物事实遵循当前会话角色快照。角色附加提示与固定记忆保持独立。
- 双花括号常用宏：基础资料、最近消息、setvar/getvar/addvar/incvar/decvar、random/pick、trim/newline、date/time、注释；支持嵌套，限制展开次数、层数和内容大小。变量本次组装内共享、下次从头计算；不是 MVU 持久化变量。未知宏保留并警告。
- 普通/续写/重生成提示类型；聊天深度与同深度顺序；示例对话按 START 和 user/char 前缀解析为消息。
- 预设内嵌 regex_scripts 会随选中的预设执行，并可在编辑中独立调整。单个规则集可保存 256 条，但执行仍限制前 32 条启用规则，原有预算和 RE2 语法边界保留。
- 大型资料编辑使用懒列表，增加名称/正文搜索与只看启用过滤，避免一次创建几百个编辑项。
- 世界书补充概率、整词匹配、玩家身份/人物描述/性格/场景扫描，以及示例对话、作者注释前后位置。
- 正文的 think/thinking/reasoning/analysis 标签可折叠；这只是模型已返回的文字，不单独请求或保存服务商原生推理字段。显示正则仍先于结构解析。

## 兼容边界

SPreset、酒馆助手、MVU、JavaScript、STscript、外部 CCv3 资源、复杂 CSS、world info outlets、全局/跨消息变量、世界书定时/互斥组/向量触发仍未实现。相关原始字段保留，世界书不支持的触发条目默认停用。模型效果不等于格式读取成功。

API 地址、密钥、采样参数、输出上限不会被预设覆盖；输出上限使用连接配置。Assistant 提示按普通消息发送，不实现服务商专有前缀补全。

随机宏和概率使用会话与当前内容生成的种子，便于同一上下文复现，并不声称与酒馆随机算法相同。有限示例与作者注释位置映射不保证复杂酒馆扩展逐字等效。Claude System 深度仍转换为独立 system 字段。

## 验证

构建与回归结果在交付前补充。数据库保持 version 3，新字段位于序列化资料 payload，旧字段默认值保留；备份格式仍 version 2。交付继续使用 0.3.0–0.3.2 升级签名、相同包名和递增版本代码。

用户提供的真实预设不加入源码仓库；通过 CI 编译的本地探针运行样本，只输出数量与展开验收结果。所有自动测试使用合成数据，不调用付费 API。
