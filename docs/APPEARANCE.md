# Role Play 0.3.1：头像与聊天阅读调整

- 角色库和会话列表默认显示角色卡图片；现有会话也能显示图片。
- 角色设定 → 从图库选择头像 → 保存。自定义头像同时用于角色库和会话列表；聊天正文不显示头像。
- “恢复默认头像”恢复导入角色卡的图片。没有图片时显示名字首字。自定义图片与原图分开保存，导出角色、完整备份和导入副本均保留两者。
- 图库图片保存为本地缩略图，处理相机旋转方向；不依赖图库链接的临时访问权限。单张原图限 16 MB、边长 20000 像素以内。
- 设置 → 显示 Token 用量；会话菜单也能切换。默认开启，选择在重启后保留。隐藏只影响显示，服务商返回的输入、输出与缓存用量继续保存。
- 回到最新的悬浮按钮改为向下箭头，保留无障碍说明与 48 dp 点击区域。

## 升级

包名仍为 `com.moyer.roleplay.next`，版本号 4 / 0.3.1-alpha。交付包使用 0.3.0 已保留的签名，可以直接更新“Role Play 新版”，保留角色、图片、会话、API 连接与密钥。

数据库从版本 2 升级为 3，仅为角色表添加空值默认的自定义头像字段；也支持从版本 1 连续升级。已有会话故事设定保留原快照，头像外观跟随当前角色卡。角色缺失时用快照中的图片。

## 验证

覆盖版本 1/2 数据库升级、图库图片缩放与 EXIF 旋转、独立图像持久化、备份和 ID 重映射、会话头像实时切换与默认图恢复、Token 菜单及设置持久化、长回复滚动箭头。最终测试与交付签名结果在验证完成后补充。
