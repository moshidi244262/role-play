# 0.3.0：角色卡显示、阅读滚动与多模型

## 本轮功能

- 开场白、已有记录和新回复中的 HTML 转换为原生可读内容。保留文字、加粗、换行、列表、表格行与 `details/summary` 折叠面板。自定义 `user_status` 包装也可以解析。不执行脚本、网络资源、链接跳转或任意 CSS；第三方状态栏的字体、阴影、颜色和复杂布局不保证原样复刻。原始消息、编辑、正则与备份仍使用原文。
- 流式回复仅在跟随状态自动滚到底部。向上拖动立即暂停跟随，即使整屏只有一条长回复也不抢回阅读位置；向下回到底部或点击“回到最新”恢复。新发消息恢复跟随。
- 角色页搜索名称、描述、性格和场景；支持多个关键词、忽略英文大小写、清空搜索与无结果提示。
- 模型选择器可搜索 API 返回的完整列表。补全 `has_more / last_id / after_id` 分页，跳过明确退役模型，限制总等待时间与异常循环。模型列表本地缓存；接口不支持列表时保留手动输入。
- DeepSeek 提供 `deepseek-flash` 与 `deepseek-v4-pro` 便捷选项，调用权限仍由服务商决定。OpenAI、Claude、Grok 不固定到一个版本。
- 聊天菜单“切换当前会话模型”复用已有密钥，仅覆盖当前会话；不改共享连接的默认模型。切换 API 连接会清除会话模型覆盖。
- 未指定具体姓名时，用户角色默认称谓改为“我”，已有默认“玩家”会话也会使用新的身份提示。支持按角色卡与情境、第一人称、第三人称三种叙述视角。显式指定的人物姓名保持。历史原文不被批量改写，模型对视角提示的遵循仍须实际阅读确认。

## 安装与迁移

此前仅保留了 0.1.0 / 0.2.0 APK，旧升级签名的私钥未能找回，不能声称本版可直接覆盖旧版。此次采用新包名 `com.moyer.roleplay.next`，桌面名称为 **Role Play 新版**；可与旧版并存，不删除旧版数据。

1. 在旧版：设置 → 导出完整备份。
2. 安装本版，设置 → 导入备份 / 聊天记录 → 导入副本。
3. 编辑导入的 API 连接，重新填写密钥；备份本来就不包含密钥。
4. 确认角色、资料、会话正常后再决定是否移除旧版。

数据库仍为 Room v2；配置 JSON 新字段有默认值，0.2.0 备份可以导入。原始角色卡与聊天保留。新模型列表缓存不含密钥。

交付采用单独保存的 `RolePlay-next-upgrade-key.keystore`，不提交到公开仓库。后续交付应取回该文件，设置 `ROLEPLAY_SIGNING_KEYSTORE` 为它的绝对路径再构建；禁止用随机 CI debug 签名替代升级签名。CI APK 仅作为构建验证产物。

## 阶段进度

继续完善阶段 3 的会话级设定和阶段 4 的受限状态栏展示。此前固定记忆、分支与上下文裁剪保留。自动摘要、完整 CCv3 资源包、群聊、语音和任意酒馆脚本仍在后续范围；本版不会为每次回复额外调用摘要模型。

## 验证

本轮包含截图结构的 HTML 样例、流式长回复向上阅读、折叠面板、角色搜索、模型搜索和分页、身份与模型覆盖、旧数据库迁移与备份恢复的回归检查。最终结果将在构建和安卓设备检查结束后补全。
