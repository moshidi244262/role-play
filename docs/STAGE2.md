# 0.2.0：连接修复、资料导入与剧情分支

此版本提供可安装的安卓客户端，并继续保留第一阶段的聊天自动保存、草稿恢复、Keystore 密钥保护与备份恢复。最低 Android 8.0。

## DeepSeek 连接修复

- 保存不再依赖模型列表加载成功。可以先保存连接，在聊天前补填模型 ID。
- DeepSeek 模板使用本轮官方接口实际返回的 `deepseek-flash`；成功获取列表后，空模型字段自动选择首个模型。
- 获取模型列表最长等待 20 秒。错误和测试结果显示在连接弹窗内，不再被弹窗遮住。
- 区分无效密钥、余额、权限、模型、限流、DNS、HTTPS 与超时问题。保存时的校验错误也显示在弹窗内。
- 没有模型时禁止开始付费生成，保留草稿。获取列表与生成测试分别操作。
- 本轮通过真实 DeepSeek 账户验证模型列表与简短生成；凭证仅从标准输入读取，没有加入仓库、测试报告或 APK。其他服务商没有真实账户验收。

如果手机仍无法连接，弹窗里的具体错误可帮助区分设备网络与配置问题。本轮没有复现用户手机的网络条件，不能断言服务商或手机网络的具体原因。

## 已实现的资料兼容

| 文件 / 功能 | 支持范围 | 明确限制 |
| --- | --- | --- |
| 角色卡 JSON | CCv2、CCv3 常用文本、旧版卡、内嵌世界书、内嵌正则、附加提示、备选开场白 | CCv3 外部资源、群聊开场白保留原字段，不加载 |
| 角色卡 PNG | `chara` / `ccv3` 元数据；tEXt、zTXt、iTXt；CRC 校验与头像缩略图 | 图片被聊天平台清除元数据后无法作为角色卡导入；文件最大 16 MB |
| 世界书 | 常驻、主关键词、辅助关键词四种逻辑、大小写、最近消息扫描、最多四轮递归、顺序、估算预算、角色前后与聊天深度插入 | 黏附、冷却、延迟、概率、互斥组、向量触发等不支持条目默认停用，导入报告注明 |
| 提示词预设 | 文本块、启停、列表顺序、System/User/Assistant、聊天内深度、酒馆 prompt_order | 标记块由本 App 的上下文结构提供；API 地址、密钥及采样参数不随导入预设生效；复杂触发停用 |
| 正则 JSON | 酒馆查找与替换、g/i/m/s、常见分组替换、角色与玩家宏、trimStrings、输入/回复/世界书作用域、深度、显示与提示词开关 | 使用有预算限制的 JVM 正则，并非完整 JavaScript 引擎；不执行 HTML、脚本、推理内容或斜杠命令 |
| 宏 | char、user、description、personality、scenario、persona | 未展开的高级宏在上下文检查中提示 |
| 本 App JSON | 完整备份、单会话、角色与关联资料、单份资料导出导入 | 角色导出是本 App 的 JSON 包，尚非可回导酒馆的 CCv2 PNG |

导入先显示数量与兼容提示，确认后新增副本；未知字段保存在原始资料中，已知凭证字段被移除。资料不会修改 API 连接或执行远程代码。

资料库中编辑世界书、预设和正则。在角色编辑中绑定资料，用于新会话；在聊天菜单的“会话设定”中可以单独调整当前会话。在资料库底部设置新会话默认资料和玩家身份。停用资料影响其所有绑定，删除资料会解除绑定。

角色卡自带的附加提示与选中的叙事预设分开保存、共同组装。基础指令要求角色事实优先于叙事风格，但提示词冲突最终仍由外部模型处理，不承诺任何模型能绝对遵循优先级。

Claude Messages 要求独立 system 字段，System 深度提示会合并成全局指令；上下文检查明确说明并展示转换后的请求正文。User/Assistant 插入保留消息顺序。

## 聊天与记忆

- “会话设定”包含玩家名称、身份说明、固定剧情记忆、作者注释、扫描深度和预算。
- 固定记忆始终作为角色上下文的一部分；达到字符预算后裁剪最早的聊天，仅影响 API 请求，本地聊天保留。
- 上下文检查显示世界书命中来源、预算跳过原因、正则警告和裁剪数量。Token 估算不是服务商账单。
- 消息菜单可以复制原文、编辑并分支、从此处分支、从玩家提问后重新生成。原会话和原回复保留。
- 重新生成创建新分支并请求当前 API，产生用量；编辑和普通分支不请求模型。
- 保存服务商返回的输入、输出和缓存命中 token 数；没有返回时不编造计数。本地持久化与服务商的提示词缓存是独立机制。
- 正则显示替换不会改写数据库原文，备份和阅读文本保留原始内容。
- 每次处理按绑定顺序执行前 32 条启用正则；超过数量会在上下文检查中提示。

## 升级与备份

数据库通过 Room 1→2 迁移新增资料、设定与用量字段，不删除旧表。第一版聊天、草稿、角色快照与连接保留。新备份 version=2，可导入旧 version=1；旧版本 App 不能识别新格式。

完整备份包含资料及默认设定；单会话包含绑定资料及角色快照需要的资料。导入重新分配全部 ID，并更新角色、会话与快照中的资料引用。密钥不进入备份，跨设备后需重新填写。

当前交付沿用同一测试签名，覆盖安装用于升级。不要卸载旧版再安装，否则系统会清除本地数据。正式发布签名、云同步、自动摘要、群聊、语音与图片仍未实现。

## 验证

安卓测试覆盖原有恢复流程、V1 数据库实际迁移、资料绑定备份合并与解除、分支保留原文与记忆、模型为空仍可保存、连接弹窗内错误与界面生命周期。
